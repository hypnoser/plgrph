Довідка: Polygraph Suite v8.1

Polygraph Suite — комплексний цифровий інструмент для поліграфологів, призначений для математичного обрахунку поліграм, побудови статистичних матриць та генерації автоматизованих звітів у відповідності до валідованих методик.
🆕 Що нового у v8.1: Додано повноцінну мультимовність — окремі версії українською, англійською та іспанською мовами (перемикач вгорі сторінки). Уточнено назви каналів пневмографії (торакальний / абдомінальний).

1. Методологія ESS-Multinomial (ESS-M)

Empirical Scoring System — Multinomial (ESS-M) — оновлення оригінальної ESS, опубліковане у 2017 році Реймондом Нельсоном. ESS-M застосовує байєсівський класифікатор із поліноміальним розподілом для аналізу даних порівняльних тестів (CQT).

1.1. Теоретичні засади

  • Емпірична основа: ESS є модифікацією федеральної 3-позиційної системи оцінювання, розробленої на базі робіт Університету Юти та Університету Джонса Гопкінса.
  • Байєсівський аналіз: ESS-M використовує байєсівську модель прийняття рішень, яка поєднує дані тесту з апріорною ймовірністю та функцією правдоподібності для обчислення апостеріорних шансів.
  • Поліноміальний розподіл: Функція правдоподібності базується на аналітичній теорії поліграфного тесту та описує ймовірності для всіх можливих комбінацій балів сенсорів.

1.2. Принципи оцінювання

  • 3-позиційна шкала: +1 (більша реакція на релевантне питання), -1 (більша реакція на порівняльне), 0 (відсутність різниці). Правило — «bigger-is-better».
  • ЕДА: Розширена шкала: +2, -2 або 0.
  • Основні ознаки: ЕДА, Кардіо, ФПГ, Пневмографія (В + Н).
  • Часові обмеження: Оцінюються лише своєчасні реакції (не пізніше 5 сек. після відповіді).

1.3. Правила прийняття рішень

Діагностичні тести

1.4. Покрокова інструкція: ESS-M

  1. Введіть П.І.Б. респондента та дату у верхній панелі.
  2. Перейдіть на вкладку ESS-M → натисніть «+ Додати обрахунок ESS-M».
  3. Оберіть Формат тесту (DLST, DLDT, LEPET, AFMGQT, BOST, Federal, Utah).
  4. За потреби змініть тип: Скринінговий / Діагностичний.
  5. Натисніть 📝 Питання та введіть тексти релевантних питань R1–R4.
  6. Введіть бали: Дихання торакальне/абдомінальне (–1, 0, +1), ЕДА (–2, 0, +2), Кардіо/ФПГ (–1, 0, +1). Символ А або ∅ — артефакт. Клавіша – — швидкий ввід від'ємного значення.
  7. Система автоматично розраховує subtotals, Grand Total, статус і ймовірнісну оцінку (Pr).
  8. Аналізуйте блок «Динаміка стану» для оцінки тренду між презентаціями.

2. Методологія Concealed Information Test (CIT)

CIT (Guilty Knowledge Test) запропонований Девідом Ліккеном у 1959 р. Єдиний психофізіологічний метод, обґрунтований теорією орієнтовної реакції (OR).

2.1. Теоретичні засади

  • Структура стимулів: Серія питань з множинним вибором: одна релевантна альтернатива (Key) та кілька нейтральних (Foils).
  • Орієнтовна реакція: Значущі стимули викликають посилені OR. Систематично сильніша реакція на Key → висновок про обізнаність.
  • Ймовірнісний захист: Ймовірність випадкового позитивного результату математично контрольована.

2.2. Система оцінювання Ліккена

  • 2 бали — найбільша реакція на Key.
  • 1 бал — друга за величиною реакція на Key.
  • 0 балів — Key не входить до двох найбільших реакцій.
КатегоріяУмоваІнтерпретація

NRIБал < кількості придатних тестівОзнак впізнання немає.
NOПридатних тестів < 3Недостатньо даних.

3.2. Прикріплення зображень

Нижче редактора розташована секція «Прикріплені зображення». Зображення зберігаються в IndexedDB браузера — окремому сховищі, що не обмежене квотою localStorage.

  • Додавання: Кнопка «＋ Додати зображення» або перетягування файлів у зону Drag & Drop.
  • Формати: JPG, PNG, WEBP, GIF, BMP — будь-яке зображення.
  • Ліміт: До 20 зображень по 5 МБ кожне.
  • Перегляд: Клік по мініатюрі → повноекранний lightbox.
  • Видалення: Кнопка «×» на мініатюрі при наведенні.
Увага: Зображення зберігаються в IndexedDB браузера. Очищення кешу браузера видалить їх разом із розрахунками. Регулярно робіть резервну копію через кнопку «📥 Зберегти».

3.3. Де зберігаються нотатки

Текст нотаток зберігається як рядок у localStorage в полі notes разом з усіма іншими даними сесії. Зображення зберігаються в IndexedDB, а в localStorage зберігаються лише їхні метадані (ім'я, розмір, дата).

4. Конфіденційність, безпека та збереження даних

Архітектура «Zero-Server»: Додаток не має серверної інфраструктури. Всі операції виконуються виключно в браузері на пристрої користувача. Жодні дані не передаються в мережу.

Формати збереження та експорту

Кнопка «📥 Зберегти» тепер підтримує два формати залежно від наявності прикріплених зображень:

СитуаціяДіяФормат
Зображень немаєАвтоматично.json — легкий, весь стан сесії
Є зображенняДіалог вибору.zip = data.json + папка images/
Є зображення, хочете тільки jsonВибрати «Скасувати» у діалозі.json без зображень

Іменування файлів

Файл автоматично отримує ім'я у форматі: polygraph-suite-Іваненко_Петро-2026-08-13.json або .zip.

Імпорт

  • Відкрити .json: Кнопка «📂» або Drag & Drop — відновлює розрахунки та нотатки. Якщо файл був збережений без зображень — вони не відновляться.
  • Відкрити .zip: Кнопка «📂» або Drag & Drop — відновлює розрахунки, нотатки і зображення (з папки images/ всередині архіву).

Офлайн-використання

Програма повністю автономна після першого завантаження. Всі бібліотеки (JSZip, Markdown-парсер) входять до складу дистрибутиву як локальні файли — CDN не використовується.

Увага: У режимі «Приватного перегляду» (Incognito) localStorage і IndexedDB можуть очищатись при закритті вікна. Регулярно експортуйте сесію.

5. Опис інтерфейсу

5.1. Глобальна панель інструментів

  • 💾 Зберегти — примусове збереження у localStorage.
  • 📂 Відкрити — імпорт .json або .zip з диска або Drag & Drop.
  • 📥 Зберегти — експорт .json (без зображень) або .zip (з зображеннями).
  • 📝 Експорт — генерація Markdown-звіту, включно з нотатками.
  • 🖨️ Друк / PDF — оптимізований друк (приховані елементи керування, збережені кольори).
  • 🗑️ Очистити все — видаляє localStorage, IndexedDB (зображення) і перезавантажує сторінку.
  • ❓ Довідка — ця сторінка.
