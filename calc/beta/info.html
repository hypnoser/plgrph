Довідка: Polygraph Suite v6.2

Polygraph Suite — це комплексний цифровий інструмент для поліграфологів, призначений для математичного обрахунку поліграм, формування матриць рішень та генерації автоматизованих звітів згідно зі стандартами Американської асоціації поліграфологів (APA).

1. Методологія ESS-Multinomial (ESS-M)

Модуль ESS-M призначений для обрахунку форматів тестів діагностики та скринінгу з використанням Емпіричної системи оцінювання (Empirical Scoring System).

  • Підтримка шкал: Алгоритм підтримує як 3-бальну, так і 7-бальну систему оцінювання реакцій (для каналів дихання, ЕДА, кардіо та PPG).
  • Генерація рішень: Система автоматично розраховує P-value (ймовірність статистичної помилки) та застосовує порогові значення (cutscores).
  • Категорії рішень згідно з APA:
    • DI / SR (Deception Indicated / Significant Responses): Значущі реакції або ознаки приховування інформації.
    • NDI / NSR (No Deception Indicated / No Significant Responses): Немає значущих реакцій.
    • INC / NO (Inconclusive / No Opinion): Невизначений результат (бракує статистичних даних для категоричного висновку).

2. Методологія Concealed Information Test (CIT)

Модуль CIT (Тест на приховану інформацію) автоматизує розрахунок ймовірностей за методом Девіда Ліккена (David Lykken) з використанням динамічного поліноміального розподілу.

  • Структура стимулів: Калькулятор дозволяє налаштовувати точну кількість стимулів у кожному тесті. Кожен тест повинен містити мінімум 4 варіанти: один Ключ (Key) та кілька Альтернативних варіантів (Foils).
  • Математична матриця: На відміну від статичних таблиць, алгоритм генерує динамічну 2D-матрицю ймовірностей на основі точної кількості наданих альтернатив (k-value).
  • Категорії рішень:
    • RI (Recognition Indicated): Впізнання виявлено. Обстежуваний володіє прихованою інформацією.
    • NRI (No Recognition Indicated): Ознаки впізнання відсутні.
    • Pr (Ймовірність необізнаності): Математично розрахована ймовірність того, що обстежуваний є необізнаним щодо деталей події (наївним об'єктом / naive subject).

3. Безпека, Конфіденційність та Офлайн-робота

Повна автономність (Zero-Server Architecture): Цей додаток розроблено з урахуванням найвищих стандартів конфіденційності. Система не використовує сервери для обробки та не відправляє ваші дані в Інтернет. Усі розрахунки та збереження виконуються виключно локально — в ізольованому кеші вашого браузера (Local Storage).

Архівування та запуск без Інтернету: Ви можете зберегти цей інструмент на свій комп'ютер назавжди.

  1. Натисніть Ctrl + S (або Cmd + S на Mac) під час перегляду сторінки програми.
  2. Збережіть сторінку у форматі "Вебсторінка, повністю" (Webpage, complete) в окрему папку.
  3. Відтепер ви можете відкривати файл index.html з цієї папки та працювати з додатком без доступу до мережі Інтернет.

4. Експорт даних та Друк (PDF)

  • Експорт у `.json`: Зберігає повний "зліпок" сесії (П.І.Б., дати, всі таблиці ESS-M та CIT) в один резервний файл. Ви можете відновити всю роботу в один клік, перетягнувши (Drag & Drop) цей файл назад у вікно браузера.
  • Експорт у `.md` (Markdown): Генерує зручний текстовий протокол дослідження, який ідеально підходить для копіювання в Microsoft Word або Obsidian (системи Zettelkasten).
  • Друк / PDF: При натисканні на кнопку принтера (або Ctrl + P) браузер автоматично застосовує спеціальні стилі друку. Зайві кнопки зникають, а дослідження оптимізуються. Примітка: вбудовано захист, який запобігає розриву таблиць та графіків ESS-M між двома сторінками формату А4 під час генерації PDF.
