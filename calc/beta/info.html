Довідка: Polygraph Suite v6.2

Polygraph Suite — це комплексний цифровий інструмент для поліграфологів, розроблений для точного математичного обрахунку поліграм, побудови статистичних матриць та генерації автоматизованих звітів у строгій відповідності до валідованих методик та стандартів Американської асоціації поліграфологів (APA).

1. Методологія ESS-Multinomial (ESS-M)

Модуль ESS-M застосовує Емпіричну систему оцінювання з поліноміальним розподілом (Empirical Scoring System - Multinomial) для математичного аналізу тестів формату CQT.

  • Принципи оцінювання: Алгоритм жорстко спирається на стандартизовану, доказову 3-бальну систему оцінювання фізіологічних ознак (дихання, ЕДА, кардіо), розроблену для ESS. Кожній ознаці присвоюється бал (-1, 0, +1) залежно від емпірично валідованих критеріїв пропорції.
  • Статистична модель: ESS-M використовує поліноміальний розподіл для розрахунку p-value (ймовірності помилки), враховуючи нормативні дані та математично визначаючи точний поріг (cutscore) для заданої кількості запитань.
  • Категорії рішень (APA Standards):
    • DI (Deception Indicated) / SR (Significant Responses): Наявність значущих реакцій (ознак приховування).
    • NDI (No Deception Indicated) / NSR (No Significant Responses): Ознак приховування не виявлено.
    • INC (Inconclusive) / NO (No Opinion): Невизначений результат (недостатньо статистичної потужності для прийняття рішення).

Інструкція з використання (ESS-M):

  1. 1 У верхній панелі введіть П.І.Б. респондента та Дату дослідження.
  2. 2 Перейдіть на вкладку ESS-M та натисніть кнопку "+ Додати обрахунок ESS-M".
  3. 3 Вкажіть формат тесту (Діагностика або Скринінг) та тип (You Phase, ZCT, LEPET тощо).
  4. 4 Додайте необхідну кількість контрольних та релевантних питань за допомогою відповідних кнопок.
  5. 5 Введіть вручну оцінені бали (-1, 0, 1) для каналів Пневмо (P1, P2), ЕДА (EDA) та Кардіо/PPG (CV) у відповідні клітинки.
  6. 6 Система автоматично розрахує підсумкові суми, P-value та згенерує обґрунтоване категорійне рішення.

2. Методологія Concealed Information Test (CIT)

Модуль CIT (Тест на приховану інформацію) автоматизує розрахунок математичної ймовірності за класичною методологією (D. Lykken) з використанням динамічних імовірнісних матриць.

  • Структура стимулів: Калькулятор підтримує різну кількість стимулів (мінімум 4). Для кожного питання необхідно визначити Ознаку (Theme), позначити один стимул як Ключ (Key), а решту залишити як Альтернативи (Foils).
  • Обробка даних: Вводиться бал електрошкірної активності (ЕДА) для ключового стимулу — традиційно "2" (найбільша реакція), "1" (друга за величиною) або "0" (інше).
  • Категорії рішень:
    • RI (Recognition Indicated): Впізнання виявлено. Сумарний бал свідчить про обізнаність.
    • NRI (No Recognition Indicated): Ознак впізнання не виявлено.
    • Pr (Необізнаність): Динамічно розрахована ймовірність (p-value) того, що фіксований результат досягнуто випадково обстежуваним, який не володіє деталями (naive subject).

Інструкція з використання (CIT):

  1. 1 Перейдіть на вкладку CIT та натисніть "+ Додати дослідження CIT".
  2. 2 У створеному блоці натисніть іконку шестірні (⚙) біля тесту.
  3. 3 У модальному вікні введіть Назву ознаки (наприклад, "Колір авто"), додайте варіанти відповідей (мінімум 4) і позначте один з них як "Ключ".
  4. 4 Введіть оцінений бал ЕДА (0, 1 або 2) у колонку поруч із тестом. Якщо виявлено артефакт, введіть букву "А".
  5. 5 Матриця праворуч динамічно адаптується під кількість тестів та видасть рішення (RI/NRI) з відповідним рівнем Pr.

4. Експорт даних та створення Звітів

  • Експорт у `.json`: Натисніть "Зберегти (.json)", щоб завантажити файл-зліпок сесії (містить дані обох методик). Ви можете в будь-який момент відновити дослідження, натиснувши "Відкрити" або просто перетягнувши (Drag & Drop) файл у вікно браузера.
  • Експорт у `.md` (Markdown): Натисніть "Експорт", щоб створити зручний текстовий протокол. Його ідеально використовувати для інтеграції в Microsoft Word, системи Obsidian (Zettelkasten) або Telegram-звіти.
  • Друк у PDF: Натискання кнопки принтера (або Ctrl + P) автоматично застосовує оптимізовані стилі друку. Зайві елементи керування ховаються. Сервіс автоматично форматує сторінки так, щоб таблиці та графіки ESS-M не розривалися навпіл під час друку.
