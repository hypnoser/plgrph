ESS-M Calculator v5.0

ESS-M Calculator — це спеціалізований інструмент поліграфолога, розроблений для математично точного підрахунку балів за системою Empirical Scoring System - Multinomial. Програма автоматизує рутину, гарантує повну відповідність стандартам APA (American Polygraph Association) та нівелює людський фактор при складанні звітів.

🛡️ КРИТИЧНО: Приватність та Безпека даних

Цей додаток створено за принципом Zero-Knowledge Architecture (Нульове розголошення):

  • Автономність: Програма не має серверів і не передає дані в Інтернет. Усі підрахунки відбуваються локально на вашому пристрої.
  • Вразливість кешу: Дані автоматично зберігаються лише в тимчасовий кеш браузера (localStorage). Якщо ви очистите історію браузера або закриєте вкладку в режимі "Інкогніто", всі поточні тести безповоротно зникнуть.
  • Єдиний захист: Використовуйте кнопку 📥 (Завантажити JSON), щоб створити зашифрований файл-бекап на вашому ПК. Для відновлення роботи просто перетягніть цей файл у вікно калькулятора.
  • Пароль: Для входу у програму завжди використовується майстер-пароль: plgrph.

🎯 Для кого цей інструмент?

Калькулятор розроблений для практикуючих поліграфологів, які використовують методику багатономіального емпіричного оцінювання (ESS-M) у:

  • Багатотемних скринінгових перевірках (AFMGQT, LEPET).
  • Однотемних діагностичних розслідуваннях (ZCT, DLDT, Federal).

🛠️ Ключові методологічні функції

1. Сувора валідація даних

Калькулятор не дозволить вам зробити помилку в цифрах. Спроба ввести текст або недопустимий бал буде заблокована. Увага до ЕДА: Згідно зі стандартами ESS, канал електродермальної активності оцінюється лише у -2, 0 або 2 бали (правило 2:1). Введення 1 або -1 для ЕДА автоматично ігнорується.

2. Розумне дихання та Фізіологічний конфлікт

Програма аналізує верхнє та нижнє дихання в комплексі:

  • Якщо обидва канали порожні — це Артефакт (втрата даних ∅).
  • Якщо на верхньому диханні бал +1, а на нижньому -1 — сума дорівнює нулю, але калькулятор розпізнає це як Фізіологічний конфлікт і маркує його золотим трикутником ⚠.

3. Диференційна вага артефактів (Rule of 25%)

Втрата каналу ЕДА (через артефакт) штрафується у 2 бали надійності, тоді як Пневмо чи Кардіо — у 1 бал. Якщо в межах одного питання втрачено ≥ 25% інформації (наприклад, злетів датчик), цьому питанню автоматично присвоюється статус NO (No Opinion).

4. Автоматична контамінація (Spot Rule)

У скринінгових тестах галочка "🔒 Контам." гарантує виконання жорсткого правила: якщо хоча б одне питання в тесті отримало статус SR (Значуща реакція), загальний статус NSR блокується, і всі інші позитивні питання отримують статус INC.

📖 Покроковий алгоритм роботи

  1. Вхід: Запустіть файл index.html та введіть пароль plgrph.
  2. Ініціалізація: Введіть П.І.Б. респондента та виберіть дату. Ці дані сформують назву ваших файлів експорту (напр., ess-Ivanov_I-2026-08-01.md).
  3. Створення тесту: Натисніть "Додати обрахунок". Обов'язково оберіть формат тесту (DLST, AFMGQT тощо) у лівому верхньому куті, щоб розблокувати потрібну кількість колонок.
  4. Внесення даних: Переносьте бали з поліграми.
    Лайфхак: Натисніть клавішу - (мінус), щоб миттєво ввести від'ємне значення. Клавіша Enter перекидає курсор на клітинку нижче.
  5. Артефакти: Якщо ділянка нечитабельна, введіть літеру А або два нулі 00. Клітинка стане оранжевою, позначаючи втрату даних.
  6. Редактор питань: Натисніть кнопку 📝 Питання і впишіть реальну семантику (текст запитань).

📊 Експорт та Звітність

Забудьте про копіювання таблиць у Word. У верхній панелі є потужні інструменти експорту:

  • 📥 Експорт JSON: Завантажує "сирий" файл бази даних. Використовуйте його, щоб зберегти прогрес або передати файл колезі (який відкриє його через кнопку "📂 Відкрити").
  • 📝 Експорт Markdown (.md): Ідеальний текстовий звіт для ваших архівів (Zettelkasten, Obsidian, Notion). Генерує готовий документ з таблицями, метаданими, кольоровим маркуванням статусів (NSR - зелений, SR - червоний) та автоматичним висновком по всім створеним тестам.
  • 🖨️ Друк / PDF: Форматує сторінку під офіційний бланк формату А4.
