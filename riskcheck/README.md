# RiskCheck by PLGRPH

Оцінка ризиків при наймі на ключові посади. Методика поліграфолога Сергія Коржова.

## Швидкий старт

1. Завантажте цю папку на GitHub у репозиторій `riskcheck`
2. Увімкніть GitHub Pages (Settings → Pages → main branch)
3. Сайт буде доступний за адресою: `https://hypnoser.github.io/riskcheck/`
4. Для email-розсилки налаштуйте Google Apps Script (див. `docs/ai-integration.md`)

## Структура

- `index.html` — основна сторінка з усім функціоналом
- `assets/css/main.css` — стилі
- `assets/js/app.js` — логіка (роутинг, калькулятор, дерево рішень, звіт)
- `pages/privacy.html` — Політика конфіденційності
- `pages/disclaimer.html` — Дисклеймер
- `email-templates/` — 3 шаблони листів для воронки
- `docs/` — інструкції з налаштування
