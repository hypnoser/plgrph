Help: Polygraph Suite v8.1

Polygraph Suite is a comprehensive digital tool for polygraph examiners, designed for mathematical polygram scoring, building statistical matrices, and generating automated reports in accordance with validated methodologies.
🆕 What's new in v8.1: Added full multi-language support — separate Ukrainian, English, and Spanish versions (language switcher at the top of the page). Clarified pneumograph channel names (thoracic / abdominal).

1. Empirical Scoring System — Multinomial (ESS-M) Methodology

Empirical Scoring System — Multinomial (ESS-M) is an update of the original ESS, published in 2017 by Raymond Nelson. ESS-M applies a Bayesian classifier with a multinomial distribution to analyze Comparison Question Test (CQT) data.

1.1. Theoretical Basis

  • Empirical foundation: ESS is a modification of the federal 3-position scoring system, developed based on research at the University of Utah and Johns Hopkins University.
  • Bayesian analysis: ESS-M uses a Bayesian decision-making model that combines test data with a prior probability and a likelihood function to compute posterior odds.
  • Multinomial distribution: The likelihood function is based on the analytic theory of polygraph testing and describes the probabilities for all possible combinations of sensor scores.

1.2. Scoring Principles

  • 3-position scale: +1 (larger reaction to the relevant question), -1 (larger reaction to the comparison question), 0 (no difference). Rule — "bigger-is-better".
  • EDA: Extended scale: +2, -2, or 0.
  • Primary features: EDA, Cardio, PPG, Pneumograph (Upper + Lower).
  • Time constraints: Only timely reactions are scored (no later than 5 sec. after the stimulus).

Artifacts: If ≥25% of data within a test is lost, it is automatically classified as NO (No Opinion).

1.4. Step-by-Step Instructions: ESS-M

  1. Enter the examinee's full name and date in the top panel.
  2. Go to the ESS-M tab → click "+ Add ESS-M Calculation".
  3. Select the Test Format (DLST, DLDT, LEPET, AFMGQT, BOST, Federal, Utah).
  4. If needed, change the type: Screening / Diagnostic.
  5. Click 📝 Questions and enter the texts of relevant questions R1–R4.
  6. Enter scores: Breathing Thoracic/Abdominal (–1, 0, +1), EDA (–2, 0, +2), Cardio/PPG (–1, 0, +1). Symbol A or ∅ marks an artifact. Press – for quick negative value entry.
  7. The system automatically calculates subtotals, Grand Total, status, and the probability estimate (Pr).
  8. Review the "State Dynamics" block to assess the trend between presentations.

2. Concealed Information Test (CIT) Methodology

CIT (Guilty Knowledge Test) was proposed by David Lykken in 1959. It is the only psychophysiological method properly substantiated by scientific research and the orienting response (OR) theory.

2.1. Theoretical Basis

  • Stimulus structure: A series of multiple-choice questions, each containing one relevant alternative (Key) and several neutral alternatives (Foils).
  • Orienting response: Significant stimuli evoke enhanced OR. Systematically stronger reaction to the Key → indicates awareness.
  • Probabilistic protection: The probability of a random positive result is mathematically controlled.

2.2. Lykken Scoring System

  • 2 points — largest reaction to the Key.
  • 1 point — second-largest reaction to the Key.
  • 0 points — Key is not among the two largest reactions.

3. "Notes" Tab NEW v8.1

The "📝 Notes" tab is the examiner's workspace for recording unstructured information: observations during testing, behavioral markers, conclusions, and examination context. Notes are tied to a specific examination (examinee), not to an individual test.

3.1. Markdown Editor

The editor supports two modes, switched via buttons at the top of the tab:

✏️ Edit Mode

A plain text field. Write in Markdown format — the syntax is converted to formatted text when you switch to preview mode.

👁 Preview Mode

Markdown is compiled into readable HTML: headings, bold/italic, lists, quotes, code blocks. Supported syntax below.

3.2. Attaching Images

Below the editor is the "Attached Images" section. Images are stored in the browser's IndexedDB — a separate storage that is not limited by the localStorage quota.

  • Adding: "＋ Add Image" button or drag files into the Drag & Drop zone.
  • Formats: JPG, PNG, WEBP, GIF, BMP — any image.
  • Limit: Up to 20 images of 5 MB each.
  • Viewing: Click on a thumbnail → full-screen lightbox.
  • Deleting: "×" button on the thumbnail on hover.
Note: Images are stored in the browser's IndexedDB. Clearing the browser cache will delete them along with the calculations. Back up regularly using the "📥 Save" button.

3.3. Where Notes Are Stored

Note text is stored as a string in localStorage in the notes field along with all other session data. Images are stored in IndexedDB, while localStorage only holds their metadata (name, size, date).

4. Privacy, Security, and Data Storage

"Zero-Server" architecture: The application has no server infrastructure. All operations are performed exclusively in the browser on the user's device. No data is transmitted over the network.

Save and Export Formats

The "📥 Save" button now supports two formats depending on whether images are attached:

SituationActionFormat
No imagesAutomatic.json — lightweight, full session state
Images presentChoice dialog.zip = data.json + images/ folder
Images present, want JSON onlyChoose "Cancel" in the dialog.json without images

File Naming

The file automatically gets a name in the format: polygraph-suite-Smith_John-2026-08-13.json or .zip.

Import

  • Open .json: "📂" button or Drag & Drop — restores calculations and notes. If the file was saved without images, they will not be restored.
  • Open .zip: "📂" button or Drag & Drop — restores calculations, notes, and images (from the images/ folder inside the archive).

Offline Use

The application is fully autonomous after the first load. All libraries (JSZip, Markdown parser) are included in the distribution as local files — no CDN is used.

Note: In "Private Browsing" mode (Incognito), localStorage and IndexedDB may be cleared when the window is closed. Export your session regularly.
