Довідка: Polygraph Suite v6.2

Polygraph Suite — це комплексний цифровий інструмент для поліграфологів, призначений для математичного обрахунку поліграм, побудови статистичних матриць та генерації автоматизованих звітів у відповідності до валідованих методик, що використовуються в поліграфній практиці.

1. Методологія ESS-Multinomial (ESS-M)

Empirical Scoring System — Multinomial (ESS-M) — це оновлення оригінальної Empirical Scoring System (ESS), опубліковане у 2017 році Реймондом Нельсоном. ESS-M застосовує байєсівський класифікатор із поліноміальним (multinomial) розподілом як функцією правдоподібності (likelihood function) для аналізу даних порівняльних тестів (Comparison Question Tests, CQT).

1.1. Теоретичні засади

  • Емпірична основа: ESS є модифікацією федеральної 3-позиційної системи оцінювання, розробленої на базі робіт Університету Юти та Університету Джонса Гопкінса. Вперше опублікована у 2008 році, ESS стала однією з найпоширеніших систем аналізу даних поліграфа у США та інших країнах.
  • Байєсівський аналіз: ESS-M використовує байєсівську модель прийняття рішень. Байєсівський аналіз поєднує дані тесту з апріорною ймовірністю (prior probability) та функцією правдоподібності для обчислення апостеріорних шансів (posterior odds) обману чи правдивості. На відміну від p-значень оригінальної ESS, апостеріорні шанси мають більш інтуїтивний і практичний зміст — вони кількісно визначають силу доказів на користь категорійного висновку.
  • Поліноміальний розподіл: Функція правдоподібності ESS-M базується на аналітичній теорії поліграфного тесту: більші зміни фізіологічної активності спостерігаються на різних типах стимулів залежно від обману чи правдивості у відповідь на релевантні цільові стимули. Референтний розподіл описує ймовірності, пов'язані з числовими балами для всіх можливих комбінацій балів усіх реєструючих сенсорів.

1.2. Принципи оцінювання

  • 3-позиційна шкала: Для кожного сенсора (дихання, ЕДА, кардіо/ФПГ) використовується стандартизована 3-позиційна шкала оцінювання: +1 (більша реакція на релевантне питання), -1 (більша реакція на порівняльне питання), 0 (відсутність відмінної різниці). Правило оцінювання — «bigger-is-better»: оцінюється будь-яка різниця в амплітуді реакції між релевантним та порівняльним питанням.
  • ЕДА (Electrodermal Activity): Оцінюється за розширеною шкалою: +2, -2 або 0.
  • Основні ознаки (Primary Features):
    • ЕДА: амплітуда електродермальної реакції.
    • Кардіо: підвищення відносного артеріального тиску (може вимірюватися на рівні базового, середнього або систолічного тиску).
    • ФПГ (Finger Pulse Amplitude): звуження (зменшення) амплітуди пульсу на кінчику пальця.
    • Пневмографія: оцінюється за сукупністю дихання «В» (вдих/верхня лінія) та «Н» (видих/нижня лінія).
  • Часові обмеження: оцінюються лише своєчасні реакції. Не оцінюються реакції, що починаються до стимулу або пізніше ніж через 5 секунд після відповіді.
  • Якість даних: не оцінюються дані, що містять рухові артефакти, нестабільні сегменти, аномально сповільнене або прискорене дихання, а також дані підвищеної або зниженої якості (dampened/exaggerated).

1.3. Правила прийняття рішень (Decision Rules)

Правила ESS-M передбачають двостадійний аналіз. Значення alpha зазвичай встановлюється на рівні .05 для обох класифікацій; для скринінгових тестів з кількома питаннями застосовується статистична корекція на кратність порівнянь (multiplicity correction) за методом Бонферроні.

1.4. Покрокова інструкція: модуль ESS-M

  1. У верхній панелі головного вікна введіть П.І.Б. респондента та Дату проведення дослідження. Ці дані будуть застосовані до всіх тестів у сесії.
  2. Перейдіть на вкладку ESS-M та натисніть кнопку «+ Додати обрахунок ESS-M».
  3. У випадаючому списку «Формат тесту» оберіть відповідну методику (DLST, DLDT, LEPET, AFMGQT, BOST, Federal, Utah тощо). Формат автоматично визначить кількість релевантних питань (RQs) та тип тесту (скринінговий чи діагностичний).
  4. За потреби змініть тип тесту перемикачем Скринінговий / Діагностичний. Деякі формати (наприклад, Federal ZCT, Utah ZCT, BOST) за замовчуванням примусово встановлюють діагностичний режим.
  5. Натисніть кнопку 📝 Питання, щоб відкрити модальне вікно. У ньому введіть текст релевантних питань (R1, R2, R3, R4). Ці дані відображатимуться у підказках заголовків стовпців таблиці та експортуватимуться у звіт.
  6. Введіть оцінені бали у відповідні клітинки таблиці:
    • Дихання «В» та «Н»: –1, 0, +1 (або символ А / ∅ для позначення артефакту).
    • ЕДА: –2, 0, +2 (або А / ∅).
    • Кардіо: –1, 0, +1 (або А / ∅).
    • ФПГ: –1, 0, +1 (або А / ∅).
    Для швидкого введення від'ємного значення натисніть клавішу – (мінус) — система автоматично підставить -1 (або -2 для ЕДА).
  7. Система автоматично розрахує:
    • суму пневмографії для кожного питання;
    • subtotal для кожного RQ;
    • chart total для кожної презентації;
    • Grand Total та категорійний висновок (DI/NDI/INC або SR/NSR/INC);
    • ймовірнісну оцінку (Pr) відповідно до референтних таблиць ESS-M.
  8. Перегляньте блок «Графічний баланс реактивності» — маркер показує положення Grand Total на шкалі від –12 до +12.
  9. Перейдіть до блоку «Динаміка стану» для аналізу тренду між презентаціями (charts). Використовуйте перемикачі Σ, R1, R2, R3, R4 для відображення відповідних ліній на графіку та текстового аналізу вектора реактивності.
  10. Якщо потрібно виключити певну презентацію з аналізу — зніміть галочку Chart #4 або Chart #5 у заголовку відповідного блоку таблиці.
  11. Для додавання нового тесту повторіть кроки 2–10. Кожен тест є незалежним і має власний формат, тип та набір питань.
Важливо: Якщо ви намагаєтеся змінити формат тесту на такий, що має менше релевантних питань, ніж поточний, а в «зайвих» стовпцях уже введено дані — система заблокує цю дію із попередженням. Спочатку очистіть дані зайвих стовпців або натисніть «Очистити дані».

2. Методологія Concealed Information Test (CIT)

Concealed Information Test (CIT), класично відомий як Guilty Knowledge Test (GKT), був запропонований Девідом Ліккеном у 1959 році. CIT — це єдиний психофізіологічний метод, належним чином обґрунтований науковими дослідженнями та теорією орієнтовної реакції (orienting response, OR).

2.1. Теоретичні засади

  • Структура стимулів: CIT використовує серію питань з множинним вибором, де кожне питання містить одну релевантну альтернативу (Probe / Key) та кілька нейтральних (нейтральних) альтернатив (Foils). Нейтральні альтернативи підбираються так, щоб невинний обстежуваний не міг відрізнити їх від ключової.
  • Орієнтовна реакція: Релевантні альтернативи є значущими лише для обізнаних (винних) осіб. Існує значна кількість доказів, переважно з досліджень орієнтовних реакцій, що значущі стимули викликають посилені орієнтовні реакції. Таким чином, якщо фізіологічні реакції обстежуваного на релевантну альтернативу систематично сильніші, ніж на нейтральні, робиться висновок про наявність прихованої інформації.
  • Ймовірнісний захист: Оскільки ймовірність того, що невинний обстежуваний випадково продемонструє сильнішу реакцію на релевантну альтернативу, залежить лише від кількості питань та кількості альтернатив у кожному питанні, цю ймовірність можна математично контролювати, забезпечуючи максимальний захист для невинних.
  • Обмеження інтерпретації: Виявлення прихованої інформації не обов'язково означає обман чи вину, оскільки існування прихованих знань може мати інші пояснення. Обман чи вина можуть бути виведені лише опосередковано та потребують додаткового розслідування.

2.2. Система оцінювання Ліккена (Lykken Scoring)

Найдослідженішим та найпоширенішим методом оцінювання CIT є система Ліккена (Lykken, 1959). Вона передбачає ранжування амплітуд електродермальної реакції (EDR) у межах кожного блоку (test) за шкалою від 2 до 0:

  • 2 бали — найбільша реакція спостерігається на ключовий стимул (Key).
  • 1 бал — друга за величиною реакція спостерігається на ключовий стимул.
  • 0 балів — ключовий стимул не входить до двох найбільших реакцій.

Реакції на перший буферний стимул (buffer) ігноруються. Якщо виявлено артефакт, який унеможливлює оцінювання, вводиться символ А — такий тест визнається непридатним (artifact) і виключається з підсумкового розрахунку.

2.3. Статистична модель та висновки

Калькулятор використовує поліноміальний розподіл для динамічного розрахунку ймовірності того, що зафіксований сумарний бал міг бути отриманий випадково необізнаним обстежуваним (naive subject). Ймовірність Pr (необізнаність) розраховується з урахуванням фактичної кількості придатних тестів та кількості альтернатив у кожному питанні.

2.4. Покрокова інструкція: модуль CIT

  1. Перейдіть на вкладку CIT та натисніть кнопку «+ Додати дослідження CIT».
  2. У верхньому полі введіть назву дослідження (наприклад, «Вогнепальна зброя», «Колір автомобіля»).
  3. Кожен блок CIT автоматично створюється з 4 тестами. Для редагування питання натисніть іконку шестірні ⚙ поруч із відповідним тестом.
  4. У модальному вікні:
    • Введіть Назву ознаки (Theme) — короткий опис предмета дослідження.
    • Введіть усі варіанти відповідей (мінімум 4). За замовчуванням — 4 альтернативи.
    • Радіокнопкою позначте ту альтернативу, яка є Ключем (Key / Probe) — тобто деталлю, відомою лише обізнаній особі.
    • За потреби додайте додаткові альтернативи кнопкою «+ Додати варіант відповіді».
    • Натисніть «💾 Зберегти».
  5. У полі «Бал ЕДА» для кожного тесту введіть оцінку за методикою Ліккена: 0, 1 або 2. Якщо виявлено артефакт, введіть А — тест буде позначено як непридатний, але саме питання збережеться.
  6. Система автоматично розрахує:
    • кількість придатних тестів;
    • загальний бал (sum score);
    • категорійний висновок (RI / NRI / NO);
    • ймовірність Pr (необізнаність) у відсотках;
    • динамічну ймовірнісну матрицю, адаптовану під кількість тестів та кількість альтернатив.
  7. У блоці «Висновок» відображається повний текстовий аналіз із зазначенням сумарного балу, кількості тестів та розрахованої ймовірності.
  8. Для додавання нового тесту в межах одного дослідження натисніть «+ Додати тест». Для створення нового дослідження поверніться до кроку 1 цього розділу.

3. Конфіденційність, безпека та локальне зберігання даних

Архітектура «Zero-Server» (без серверної частини): Polygraph Suite розроблено за принципом повної автономності. Додаток не має серверної інфраструктури, не відправляє, не перехоплює та не зберігає жодних даних у мережі Інтернет. Усі операції з інформацією респондентів виконуються виключно в оперативній пам'яті та локальному сховищі (localStorage) браузера, на пристрої користувача.

Як зберігаються дані

  • Автозбереження: Під час роботи всі введені дані (П.І.Б., дата, бали ESS-M, питання та бали CIT) автоматично зберігаються у локальному кеші браузера (localStorage). Це дозволяє не втратити прогрес при випадковому закритті вкладки або перезавантаженні сторінки.
  • Термін зберігання: Дані зберігаються до моменту явного очищення (кнопка «🗑️ Очистити все») або ручного видалення localStorage через налаштування браузера.
  • Неможливість віддаленого доступу: Оскільки дані ніколи не покидають пристрій користувача, жодна третя сторона (включаючи розробників) не має технічної можливості отримати до них доступ.

Імпорт та експорт даних

Для перенесення даних між пристроями, створення резервних копій або інтеграції з зовнішніми системами передбачено функції імпорту та експорту у форматі .json:

  • Експорт (.json): Натисніть кнопку «📥 Зберегти (.json)» на головній панелі. Буде завантажено файл-зліпок усієї поточної сесії (П.І.Б., дата, всі тести ESS-M та CIT). Файл можна зберегти на зовнішньому носії, у хмарному сховищі або передати колезі.
  • Імпорт (.json): Натисніть «📂 Відкрити (.json)» та оберіть раніше збережений файл. Альтернативно — просто перетягніть (Drag & Drop) файл .json у вікно браузера. Після підтвердження сторінка автоматично оновиться з відновленими даними.
  • Експорт у Markdown (.md): Кнопка «📝 Експорт» генерує текстовий протокол у форматі Markdown, який містить повний звіт з усіх тестів. Його зручно використовувати для подальшого редагування в Microsoft Word, системах Obsidian (Zettelkasten) або для публікації в Telegram.

Офлайн-використання

Програма є повністю автономною. Після першого завантаження сторінки ви можете працювати без підключення до Інтернету. Для цього збережіть сторінку як «Вебсторінка, повністю» (Ctrl + S) або скористайтеся функцією «Завантажити архів програми (.zip)» на цій сторінці.

Увага: Функція автозбереження у localStorage залежить від налаштувань браузера. Якщо у вас активовано режим «Приватного перегляду» (Incognito / Private Mode) або налаштовано очищення localStorage при закритті браузера, дані можуть бути втрачені. Рекомендується регулярно експортувати сесію у файл .json.

4. Опис інтерфейсу та додаткових функцій

4.1. Глобальна панель інструментів

Панель розташована під заголовком і є спільною для обох вкладок (ESS-M та CIT):

  • 💾 Зберегти — примусове збереження поточного стану у localStorage. Індикатор статусу праворуч показує «🟢 Дані збережено» або «🟠 Є незбережені зміни».
  • 📂 Відкрити (.json) — імпорт файлу сесії з диска.
  • 📥 Зберегти (.json) — експорт файлу сесії на диск.
  • 📝 Експорт — генерація Markdown-звіту та його завантаження.
  • 🖨️ Друк / PDF — виклик діалогу друку з оптимізованими стилями (приховані елементи керування, збережені кольори, заборона розриву таблиць навпіл).
  • 🗑️ Очистити все — повне видалення всіх даних з localStorage та оновлення сторінки. Потребує підтвердження.
  • ❓ Довідка — відкриття цієї інформаційної сторінки.

4.2. Поле респондента

Під панеллю інструментів розташовані два поля:

  • П.І.Б. респондента — текстове поле для введення прізвища, імені та по батькові обстежуваної особи. Використовується у звітах та назві експортованих файлів.
  • 📅 Дата — календарне поле для вказівки дати проведення дослідження.

4.3. Вкладки методик

ESS-M

Вкладка для роботи з порівняльними тестами (CQT). Підтримує формати DLST, DLDT, LEPET, AFMGQT (2–4 RQ), BOST, Federal (Bi-Zone, ZCT), Utah (ZCT, MGQT). Кожен тест містить матрицю оцінювання, графічний баланс реактивності та блок динамічного аналізу.

CIT

Вкладка для роботи з тестом на приховану інформацію. Підтримує довільну кількість досліджень, кожне з яких містить набір тестів із налаштовуваними альтернативами та ключем. Автоматично будує динамічну ймовірнісну матрицю.

4.4. Друк та експорт у PDF

При натисканні Ctrl + P (або кнопки «🖨️») застосовуються оптимізовані стилі друку:

  • Приховані панелі інструментів, вкладки, кнопки додавання/видалення, модальні вікна.
  • Збережені кольові позначення статусів (SR — червоний, NSR — зелений, INC — сірий, артефакти — оранжевий).
  • Таблиці та графіки не розриваються навпіл між сторінками (page-break-inside: avoid).
  • Кожен тест ESS-M та кожен блок CIT починається з нової сторінки для зручності читання.
