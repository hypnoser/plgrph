Що таке Polygraph Suite

Polygraph Suite — це безкоштовний калькулятор для поліграфологів, призначений для розрахунку результатів психофізіологічних досліджень (ПФД) за трьома валідованими науковими методиками: ESS-M, CIT та R&I (FROSS). Застосунок доступний трьома мовами — українською, англійською та іспанською — і призначений для практикуючих фахівців.

Застосунок розроблено командою PLGRPH — того самого центру оцінки достовірності інформації, що проводить поліграфологічні перевірки з 2013 року й надає методологічну підтримку фахівцям.

Спробувати калькулятор можна безпосередньо за посиланням plgrph.com/ps/ — без встановлення, якщо йдеться про браузерну версію.

Архітектура Zero-Server: чому це важливо

Психофізіологічні дослідження оперують чутливими персональними даними. Для цієї категорії інформації спосіб зберігання не менш важливий, ніж точність самої методики підрахунку.

Немає серверної інфраструктури

Застосунок не надсилає дані на бекенд, тому що бекенда, який міг би їх прийняти, не існує.

Локальне зберігання

Дані сесії — у localStorage браузера, зображення нотаток — в IndexedDB на пристрої користувача.

Онлайн і офлайн

Веб-версія працює без мережі після завантаження; окремо доступна автономна офлайн-збірка файлів.

Будь-яка операційна система

Немає прив'язки до конкретної ОС — застосунок працює в браузері на Windows, macOS і Linux.

Три валідовані наукові методики

Кожна вкладка калькулятора реалізує окрему, самостійну методику аналізу — вони покривають різні типи тестів і різні задачі поліграфологічного дослідження.

Порівняльний тест (CQT)

ESS-M

Empirical Scoring System — Multinomial. Оновлена версія ESS, опублікована Реймондом Нельсоном у 2017 році. Використовує баєсівський класифікатор із поліноміальним розподілом для аналізу даних порівняльних тестів. Підтримує скринінговий і діагностичний формати з окремим оцінюванням п'яти фізіологічних каналів: грудного й черевного дихання, електродермальної активності (ЕДА), кардіо та фотоплетизмографії.

  • Вердикт: SR / NSR / NO або DI / NDI / INC
  • 5 фізіологічних каналів окремо
  • Формати DLST, DLDT, LEPET, AFMGQT, BOST, Federal, Utah
Прихована інформація

CIT

Concealed Information Test — тест на приховану інформацію, запропонований Девідом Ліккеном у 1959 році. Система оцінювання побудована на матриці ймовірностей Ліккена, що дозволяє статистично оцінити ймовірність володіння респондентом інформацією, недоступною непричетній особі.

  • Матриця ймовірностей Ліккена
  • Вердикт: RI / NRI / NO
  • Ґрунтується на теорії орієнтовної реакції
Скринінг, допоміжний метод

R&I / FROSS

Field Rank Order Scoring System («Велика трійка», High Three) — ранговий метод аналізу релевантних та іррелевантних питань. FROSS — допоміжний, вторинний метод: він не визначає вердикт SR/NSR/NO — це рішення поліграфолог ухвалює глобально. Метод вказує, яке релевантне питання найзначущіше для подальшого уточнюючого дослідження.

  • НЕ визначає вердикт самостійно
  • Ранжування 5 релевантних питань по 3 каналах
  • Графік значущості: топ-3 кольором

Допоміжні інструменти

Нотатки

Markdown-редактор для спостережень поліграфолога під час дослідження. Підтримує прикріплення зображень (JPG/PNG/WEBP, до 5 МБ на файл, до 20 файлів) та документів (PDF/DOC(X)/XLS(X)/PPT(X)/TXT, до 20 МБ на файл, до 20 файлів). Усі вкладення зберігаються так само локально, як і решта даних сесії.

Супервізія

Другий фахівець вводить власні бали ESS-M поруч з оригінальними — оригінальні бали при цьому лишаються нередагованими. Система в реальному часі показує позначки розбіжності по кожній комірці таблиці й підсумок: скільки оцінок збіглися, яка сумарна розбіжність, і прямо називає найпроблемніший фізіологічний канал — той із п'яти, де сума розбіжностей найвища. Корисно для навчання молодших фахівців, контролю якості й наставництва.

Для кого цей інструмент

Polygraph Suite розрахований на практикуючих фахівців трьох мовних сегментів. Інструмент не є навчальним посібником для студентів чи новачків у методі.

1

Одноосібні практикуючі поліграфологи

Власний робочий інструмент для підрахунку результатів і портативний архів обрахунків.

2

Відділи та агенції з кількома фахівцями

Обмін результатами між колегами та спільна робота над одним і тим самим респондентом.

3

Керівники й старші фахівці, що супервізують

Контроль якості роботи підлеглих поліграфологів через вкладку «Супервізія».

Розширені сценарії використання

Пункти нижче — це не окремі «функції» з окремими кнопками в інтерфейсі, а способи застосування вже наявного функціоналу (експорт/імпорт файлів, вкладка «Супервізія», захищене шифрування), скомбінованого користувачем під власну робочу практику. Усі сценарії доступні безкоштовно.

Обмін між поліграфологами при повторному тестуванні

Другий поліграфолог, який проводить додаткове дослідження раніше протестованого респондента, відкриває отриманий файл сесії у своїй копії застосунку — всі дані, нотатки, зображення й документи відновлюються повністю. Далі додає власний тест у тій самій сесії.

Надсилання результатів керівнику чи замовнику

Отримувач відкриває той самий безкоштовний застосунок за посиланням, без реєстрації, і імпортує надісланий файл — простий крок, а не бар'єр для людини, яка бачить застосунок вперше.

Проведення супервізії керівником чи старшим фахівцем

Супервізор відкриває файл у тому ж застосунку, переходить на вкладку «Супервізія», вводить власні бали поруч з оригінальними (незмінними) і бачить позначки розбіжності в реальному часі.

Виявлення систематичних помилок інтерпретації окремих каналів

Повторний незалежний підрахунок супервізором після порівняння показує розбіжність — і система автоматично вказує саме на проблемний канал за сумою розбіжностей. Це виявляє систематичну помилку конкретного фахівця, а не одноразову випадковість.

Захищений обмін файлом із чутливими даними

Передача файлу результатів через канали зв'язку, що не гарантують конфіденційності — захищений .pgse-файл марний без пароля, який передається окремим каналом.

Друк або PDF-звіт для замовника

Вбудована функція друку формує чистий структурований вивід (без службових елементів інтерфейсу) з таблицями та висновком, який зберігається як PDF через стандартний діалог друку браузера.

Архів власних обрахунків

Кожна сесія зберігається як окремий файл з автоіменуванням (ім'я респондента + дата) — портативний файл, який користувач самостійно впорядковує на своєму пристрої чи в хмарному сховищі на власний вибір.

Онлайн і офлайн: два способи використання

Polygraph Suite можна використовувати як безпосередньо в браузері з підключенням до інтернету, так і повністю автономно, без мережі.

Онлайн-версія

Відкривається за посиланням plgrph.com/ps/ у будь-якому сучасному браузері. Після першого завантаження сторінки подальша робота й розрахунки не потребують повторних звернень до мережі — усі бібліотеки локальні.

Офлайн-збірка

Для роботи там, де стабільного зв'язку немає — виїзні дослідження, режимні об'єкти, місця без покриття — доступна автономна збірка застосунку у вигляді файлів. Вона відкривається прямо з пристрою без інтернету.

Офлайн-збірка працює на будь-якій операційній системі:

Windows macOS Linux
Як отримати офлайн-версію. Автономна збірка не викладена у вільний доступ для завантаження — її висилають індивідуально за запитом користувача через Telegram або email, вказавши кількість пристроїв, для яких потрібна збірка.

Безпека й обмін файлами

Стандартний експорт

.json — без зображень і документів, або .zip — з папками images/ та documents/, з автоматичним іменуванням файлу.

Захищений експорт із паролем (.pgse)

Окрема кнопка з іконкою жовтого замка шифрує весь файл алгоритмом AES-256-GCM (ключ похідний від пароля через PBKDF2-SHA256, 150 000 ітерацій), повністю на клієнті через вбудований Web Crypto API. Файл марний без пароля, який передається окремим каналом зв'язку.

Розумний імпорт

Застосунок автоматично розпізнає формат файлу (звичайний чи захищений) і запитує пароль лише тоді, коли це необхідно.

Порівняно з ручним підрахунком

Методики ESS-M, CIT та R&I можна застосовувати і вручну — на папері чи в Excel-таблиці власної побудови. Ключова відмінність калькулятора — не в самій методиці, а в способі її застосування.

Ручний підрахунок / Excel

  • Підсумовування балів вручну — ризик арифметичної помилки
  • Візуалізації потрібно будувати самостійно
  • Формат таблиці й підхід відрізняються від фахівця до фахівця
  • Обмін файлом супроводжується ризиком розбіжностей у структурі таблиці

Polygraph Suite

  • Підрахунок балів автоматизований — арифметичні помилки виключені
  • Графік значущості FROSS і позначки розбіжностей будуються автоматично

  • Формат обміну (.json/.zip/.pgse) незмінний і сумісний між копіями застосунку

Часті запитання

Чи безпечно зберігати результати поліграфа в Polygraph Suite?
Так, за архітектурою застосунку. Усі дані зберігаються виключно в локальному сховищі браузера (localStorage та IndexedDB) на пристрої користувача і не передаються в мережу.
Яка різниця між ESS та ESS-M?
ESS-M — оновлена версія класичної ESS (Нельсон, 2017), що використовує баєсівський класифікатор із поліноміальним розподілом ймовірностей.
Чи можна користуватися Polygraph Suite офлайн, без інтернету?
Так, двома способами: веб-версія не потребує повторних звернень до мережі під час розрахунків, а для повністю автономної роботи доступна офлайн-збірка файлів, яку надсилають за індивідуальним запитом через email або Telegram — вона працює на Windows, macOS та Linux.
Скільки коштує Polygraph Suite?
Безкоштовно — включно з усіма трьома методиками, нотатками, супервізією й захищеним експортом. Окремого платного тарифу немає.
Чи можна передати результати колезі для перевірки?
Так, через експорт/імпорт файлу сесії. Отримувач відкриває той самий застосунок за посиланням і імпортує файл — усі дані відновлюються повністю.
Що таке FROSS і навіщо він потрібен?
Допоміжний ранговий метод аналізу релевантних питань у вкладці R&I. Він не визначає вердикт SR/NSR/NO — лише вказує, яке питання найзначущіше для подальшого дослідження.
Чи потрібна реєстрація або обліковий запис?
Ні, через відсутність серверної частини реєстрація непотрібна. Доступ до калькулятора захищений паролем, який видається після короткої перевірки професійних знань.
Як працює захищений експорт із паролем (.pgse)?
Вміст сесії шифрується AES-256-GCM, ключ похідний від пароля через PBKDF2-SHA256 (150 000 ітерацій), повністю на клієнті через Web Crypto API.
Чи можна використовувати застосунок для командної роботи в агенції?
Так. Обмін файлами сесій і вкладка «Супервізія» дозволяють кільком фахівцям спільно працювати над одним респондентом — без платного тарифу.
Чим Polygraph Suite відрізняється від ручного підрахунку в Excel?
Швидкістю, відсутністю арифметичних помилок, автоматичною побудовою візуалізацій і єдиним стандартизованим підходом між фахівцями та сесіями.
Чи можна роздрукувати або зберегти результат як PDF?
Так, через стандартний діалог друку браузера — вбудована функція друку формує чистий структурований вивід без службових елементів інтерфейсу.
На яких операційних системах працює офлайн-версія?
Офлайн-збірка — це локальні файли, що відкриваються в браузері з пристрою. Оскільки застосунок не залежить від ОС, а лише від браузера, він однаково працює на Windows, macOS і Linux.
